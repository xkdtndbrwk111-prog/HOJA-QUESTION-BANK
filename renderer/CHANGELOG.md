# 렌더러 변경 기록

## v0.1.0-preview.2 — 2026-11-21

- 사회 3-1 Q15·Q30, 3-2 Q13·Q22의 도표 4개 재작도(16:9 / 1600×900): 더 큰 글자, 같은 크기의 날짜 및 사건 칸, 내부 여백, 중앙 정렬
- 자료가 정답을 그대로 알려주는 표현을 새로 추가하지 않고 기존 (가)·(나)와 문항·정답·보기 유지
- `layoutHint=split`이 지정된 그림 문항을 좌측 자료·우측 보기로 우선 배치하여 실제 도표 표시 영역 확대
- 검토용 64문항 HTML과 기능 점검용 가상 데이터 HTML을 별도 버전으로 보관
- 운영 게임 미배포. 문제 카트리지 정본·승인 상태 변경 없음


## v0.1.0-preview.1 — 2026-11-21

- 별도 `renderer/` 영역 최초 분리; 문제은행과 렌더러 버전을 독립적으로 기록
- 최신 기능이 확인된 사회 5학년 3-1·3-2 rev4, 64문항 HTML을 **원본 그대로** 보존
- 기능 검증용 가상 5문항 단일 HTML 제작 (원본 콘텐츠와 분리)
- 유지한 화면 기능: A/C/D, 좌우/상하 자동 판단, 그림 확대, 3지선다, O/X
- **주관식 큰 정답 공개 → 교사 정답·오답 판정 → 중복 차단 → 다음 문항** 포함
- 범위: 오프라인 교육용 검토판. 실제 호자게임 렌더러/점수 시스템으로 배포하지 않음

### 기준 출처

- 실제 영어·사회 모든 정본 조합에 대한 독립 회귀
