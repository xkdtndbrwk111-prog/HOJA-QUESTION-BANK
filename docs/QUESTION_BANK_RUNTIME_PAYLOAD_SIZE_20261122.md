## 주의할 예외·제약

1. **영어 천재 5학년 10단원 Q21 교사 승인 시계 교정 반영:** `presentation/media/school_no_clock_review.webp`(75,242B), `clock_8_20_vector.svg`(8,878B)을 실제 사용. 과거 `clock_8_20.webp`(9,116B)는 q21에서 제외했음. 기존 `go_to_school.webp`(9,800B)은 Q04·05·07에서도 사용하므로 삭제하지 않음. 이 오버레이는 게임 로더에 별도 구현할 부분이며, 이번 용량 측정용 JSON에서는 참조를 직접 대체함.
2. **사회 승인 미디어 선택:** 원본 후보 이미지가 아니라 `effective/assets/`의 최종 자료만 채택, `display/assets/` 미리보기 중복 제외. 특히 실지도 `worldview_compare_two_real_maps.webp` 208,182B는 실제 사용 파일임.
3. **YBM 183문항:** `questions.approved.json`과 승인 ZIP 안의 정확한 31개 WebP 원본을 사용. 중복으로 저장된 6개 단원별 JSON, 이미지 data URI 테이블과 검수 HTML은 제외.
4. **과학 64문항:** 사용자가 재업로드한 승인 r1 ZIP의 `effective/cartridge.json`과 `effective/assets/`만 사용; 후보·HTML·검수 자료 제외.
5. **수학 187문항:** `HOJA_MATH_187_corrected_candidates_2026-11-22.zip` 안의 6개 `chatfix1` 후보 카트리지, WebP 36개만 사용. 교사가 Gemini에게 요청한 향후 문구·삽화 개편은 아직 미적용.
6. **향후 실제 배포 용량은 다를 수 있음:** 네트워크 전송 포맷, CDN 캐싱, 앱 버전 메타데이터, 런타임 변환 오버헤드, 파일시스템 블록 정렬과 향후 수학 삽화 교체 등에 따라 차이 발생. 게임 엔진과 기본 UI 크기는 이 수치에 **전혀 포함되지 않음**.
7. 검증용 ZIP을 계산 목적으로 만들었을 뿐 게임에서 읽히는 패키지/어댑터 개발, 운영 배포, 저작권 검사는 수행하지 않음.
